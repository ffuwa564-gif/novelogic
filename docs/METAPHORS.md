# 『二人』メタファー設計ノート

> 作品タイトル：**二人**  
> 舞台：世界には少女が二人だけ存在する。  
> 状態：**構想段階／メタファーの記録**。プロットや結末は未決定。  
> 注記：下記の「核となる意味」は作者が指定したもの。「展開の候補」は今後の検討用であり、確定設定ではない。

## 1. 中核となる四つのメタファー

| モチーフ | 核となる意味（作者指定） |
| --- | --- |
| **髪の毛** | **拘束、束縛** |
| **糸** | **翻弄、運命** |
| **ガラスの花** | **永遠、偏執、固執** |
| **目** | **希望、恐怖** |

この対応を作品の象徴的な出発点とする。ただし「髪が出たら必ず束縛」などの機械的な記号置換にはしない。**場面、二人の関係、読み手の認識によって意味が揺れる**ことを活かす。

## 2. 各モチーフの性質と使い方の候補

### 髪の毛 — 拘束、束縛

- **具体的な動き**：伸びる、結ぶ、編む、絡まる、ほどく、切る。
- **特性**：身体の一部でありながら、切り離せる。時間とともにまた伸びる。
- **意味の候補**：相手を縛るだけでなく、本人が自身の感情に拘束されること。結い直すことは関係の更新、ほどくことは拒絶にも解放にもなりうる。
- **描写の問い**：「相手の髪を結ぶ」は優しさか、所有のしるしか。相手自身がそれをどう受け取るか。

### 糸 — 翻弄、運命

- **具体的な動き**：張る、引く、たるむ、絡む、たぐる、ほどける、切れる。
- **特性**：細く、離れたものを結び、どちらから引かれたか分かりにくい。
- **意味の候補**：運命に引かれる感覚、見えない因果、自分で選んだつもりの選択。糸を切ることも新たな帰結を招く。
- **髪との違い**：髪は**身体と所有・親密さ**に根差し、糸は**外部からの作用・方向・因果**に重心がある。似ているからこそ混同しない。

### ガラスの花 — 永遠、偏執、固執

- **具体的な動き**：作る、飾る、磨く、閉じ込める、ひび割れる、砕ける。
- **特性**：咲いた姿を保てる一方で、成長しない。永続性を望むものが脆さを含む。
- **意味の候補**：美しい瞬間を永遠に保存したい願望／変化を受け入れられない固執。守るための保存が対象の自由や未来を奪いうる。
- **描写の問い**：二人のうち誰が、どの瞬間を、なぜ変えたくないのか。

### 目 — 希望、恐怖

- **具体的な動き**：見る、見つめる、見返す、逸らす、閉じる、開く、映す。
- **特性**：見る側と見られる側が生まれる。同じ視線でも意味は一致しない。
- **意味の候補**：相手を見つける希望／相手を失う未来を見てしまう恐怖。理解したい視線が、見られる側には監視として働くこともある。
- **描写の問い**：「見つめられる」は救いか脅威か。目を閉じることは逃避か信頼か。

## 3. モチーフ間の関係（仮説）

四つを個別の暗号にせず、二つ以上が同じ場面に登場したときの相互作用を考える。

| 組合せ | 生まれうる問い |
| --- | --- |
| 髪 × 糸 | 自分の意思で結んだものと、運命に結ばれたものは区別できるか。 |
| 髪 × ガラスの花 | 伸び続ける身体と、変わらない花。愛は変化することを許すか。 |
| 髪 × 目 | 見つめることが、相手を拘束することに変わる瞬間はあるか。 |
| 糸 × ガラスの花 | 変化していく運命の中で、一瞬だけを固定できるか。 |
| 糸 × 目 | 先が見えることは希望か、それとも逃れられない未来への恐怖か。 |
| ガラスの花 × 目 | 永遠に眺められる美しさは、誰にとっての幸福なのか。 |

### 一つの整理案（未確定）

- **髪＝身体と束縛**
- **糸＝因果と運命**
- **ガラスの花＝時間と固執**
- **目＝認識と希望／恐怖**

この分類は**設計補助**であり、作者の指定した意味を上書きしない。

## 4. 表現と構築の原則

1. **メタファーを台詞で解説しない。** 髪を結ぶ、糸が絡む、ガラスの花を飾る、目を逸らすなど、具体的な行為をまず描く。
2. **二人で意味が違う。** 同じ行為を一方は優しさ、もう一方は束縛と受け取ってよい。
3. **同じモチーフを変奏する。** 序盤と終盤で同じ物が現れても、そこで起きる選択によって意味を変える。
4. **生活の必然性を持たせる。** 象徴を登場させるだけの不自然な小道具や会話を増やさない。
5. **見える説明より、余白を残す。** 一つの意味に完全に固定せず、読み返すと別の解釈が成立するようにする。
6. **二人だけの世界という前提を守る。** 物語の解決を第三者へ安易に委ねず、二人の行為と関係によって意味を生み出す。
