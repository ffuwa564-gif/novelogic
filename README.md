# Novelogic

**少数の公理から、構造そのものが美しい小説を設計するプロジェクト。**

物語を「場当たり的な展開の集合」ではなく、人物・記憶・因果・視点の状態遷移から生まれる構造物として扱う。ただし数式の整合性を目的化せず、**構造が感情を生み出す**ことを最優先する。

## 試作小説

### [『橋の真ん中』](novels/hashino-mannaka.md)

**世界に存在する少女は二人だけ。** 湖を挟む二つの岸と、二人が自分たちで作った硝子の橋。橋に亀裂が生じたとき、相手を守りたい気持ちと、自分の足で渡りたい気持ちが食い違う。

全5章の完結した短編。構造の中心で二人が記憶を交換し、対称に配置された章の意味が反転する。

## 基本方針

1. **最小性**：少数の規則から豊かな展開を導く。
2. **必然性**：章を削除すると、因果または読者の理解が損なわれる。
3. **対称性と破れ**：章の配置は厳密、少女たちの感情と選択は一様にしない。
4. **不変量**：何かが保存されるからこそ、失われるものに意味が生じる。
5. **再帰性**：出会い→交換→変化という構造が場面・章・幕に現れる。
6. **創発性**：結末を押し付けず、規則と人物の選択の相互作用から導く。
7. **可読性**：数理モデルを知らない読者にも、ひとつの小説として成立させる。

## まず作る作品（プロトタイプ）

6人の少女、5幕15章。各章で異なる2人が出会い、それぞれが持つ「複製できない体験記憶」を交換する。読者は15章を通して、各人が持つ情報の偏りと関係性の変化から事件の全体像を再構成する。

**確定しているのは構造上の制約であり、人物名・事件の真相・感情の結末は未決定。** 書き始める前に因果関係の成立を検証する。

## 進め方

1. 公理と構造を定める。
2. 登場人物の欲望・誤解・選択の可能性を設計する。
3. 15章の因果と開示順序を組み立てる。
4. 第1幕で試作し、文章として面白いか検証する。
5. 構造と感情を再調整して全幕へ拡張する。

仕様変更では、数理的な**制約**と、あくまで**仮説・作劇案**である部分を区別して更新する。
